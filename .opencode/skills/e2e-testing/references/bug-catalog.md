# Bug catalog

Every row was found by this harness against the real app. Columns: symptom -> root-cause
class -> how it was detected -> fix -> regression -> **sibling search** (the grep that finds the
same defect in the twin code path). Where the fix is still open, the row says `open` - do not
describe it as fixed.

The sibling-search column exists because almost every row below recurred in a sibling first: cash
vs card, desktop vs mobile, sale vs refund, screen vs print, product vs customer adapter. Run the
grep before you call a fix done; the recipe is also Gate 6 step 6.

B1-B6 share a detection trick: capture the **payload**, decode it with an independent decoder,
and compare with the DB. `tools/27b-lbl-checks.mts` uses hand-written EAN-13 L/G/R and Code128
tables whose anchors (0/103/104/105/106) are asserted first, so a table cannot cancel an
encoder bug.
