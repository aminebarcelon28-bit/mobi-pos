# MobiPOS License Administrator (Desktop Suite)

## Lancement Rapide

```powershell
npm run license:desktop
```
ou directement :
```powershell
python admin_desktop/main.py
```

## Fonctionnalités Clés
- **Tableau de Bord & KPIs** : Statistiques en temps réel sur les clients, postes de caisse et smartphones connectés.
- **Génération de Clé** : Création instantanée de clés Crockford Base32 avec synchronisation Cloudflare Edge et modèle WhatsApp prêt à l'envoi.
- **Inspecteur d'Appareils** : Suivi en direct des HWIDs, horodatages de ping, et détachement unitaire ou réinitialisation globale de postes.
- **Gestion des Quotas & Statuts** : Ajustement à la volée des limites d'appareils et suspension/réactivation immédiate.
- **Signature Hors-Ligne (Ed25519)** : Émission de jetons JWT sécurisés pour machines sans connexion Internet.
